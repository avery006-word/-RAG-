# 科技文献智能问答系统
这是一个基于LLM和RAG的智能问答系统，基于qwen-agent框架搭建，在基础RAG框架上进行了多个优化措施，适合轻量化部署。
knowledge_base 文件夹是知识库，里面有知识库构建的代码和知识库构建成果，这里采取了制定化的父子分块策略，根据文献样本特征对分块策略添加了一些约束。
qa_dataset 文件夹包含了问答对数据集以及处理问答对数据集的代码。
base_line.py 基线系统，基础的RAG框架问答系统，不添加任何优化措施，用于对比。
chunk_optimized.py 在基线系统的基础上对父子分块策略进行了优化。
retrieval+chunk_optimized.py 在基线系统的基础上对父子分块策略进行了优化，并对检索机制进行了优化，采用“混合检索+加权倒数排名融合+交叉编码器重排序”的检索路径。
full_optimized_qa_sys.py  在 retrieval+chunk_optimized.py 的基础上对用户问题进行扩展，设计专门的提示词引导大模型判断问题是否为复杂问题（包含多个子问题），若是，则拆解为复杂问题为若干个简单子问题；若不是，则对用户问题进行同义转述，提高检索覆盖率。
context_parent_matcher.py 对系统检索结果进行标注，标注检索结果来源于哪一个父块，便于后续计算召回率和平均倒数排名。
